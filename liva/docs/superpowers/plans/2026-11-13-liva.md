# LIVA Implementation Plan

> For agentic workers: execute the independent storefront modules concurrently, then integrate and review.

**Goal:** A polished complete LIVA frontend prototype.
**Architecture:** Buildless hash router, shared browser state, independently styled catalog and commerce modules.
**Tech Stack:** HTML, CSS, JavaScript, local jQuery.
**Spec:** ../specs/2026-11-13-liva-design.md

## Global constraints
Frontend only. No API, backend, real OTP or payments. Keep all assets in the repository. English/USD. Work in supplied checkout.

## Review focus
- Reload restores bag and wishlist without invalid data breaking rendering.
- Empty cart cannot place orders and quantities remain positive.
- Unknown product/order routes display useful states.
- All dialogs close via Escape and restore focus.
- Small screens have no horizontal overflow and forms remain usable.
